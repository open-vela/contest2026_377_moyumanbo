# VelaSense 显示演示版

运行、编译、烧录和依赖说明见 [仓库 README](../../README.md)。
本应用在开机时运行，不使用 `firmware/` 中尚未完成集成的模块。

- 首页、静态趋势、呼吸练习、设置、心情弹窗。
- 数据、时钟、电量均为演示值；设置不持久保存。
- 默认每 8 秒轮播，弹窗和呼吸练习期间暂停。
- 呼吸页保留 Ready? 和阶段说明，已去掉待机重复数字。
- 中文字体随固件编译，许可证见 `fonts/OFL.txt`。
- 串口任务只请求切页；LVGL 调用始终在 UI 任务运行。
- `HAL_GetTick` 使用单调时钟；SysTick 为 1ms。
- RGB565 使用 40 行（31,200 字节）缓冲；禁用额外 framebuffer 和 TE 等待。

[主机预览与实机验证记录](../../docs/demo/validation.md)。
