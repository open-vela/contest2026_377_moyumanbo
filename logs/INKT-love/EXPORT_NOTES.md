# AI 日志导出范围

- 两份早期 Claude Code 日志沿用官方 collector 的 schema 1.0，补齐本地已采集的事件。
- Codex 日志仅来自当前 VelaSense 项目任务的两个明确选定记录文件，保留原始时间戳及用户/助手可见文本，按事件顺序编号。
- Codex 为文本快照：不含工具调用/输出、截图二进制、系统/开发者指令、私有推理、环境元数据和仅中断的续接记录。不冒充完整工具轨迹。
- 旧日志和新增日志均移除凭据及个人用户目录；思考字段不公开。替换次数记录于事件/manifest 的 redacted_count 字段。
- 没有生成、补写或润色原始对话。日志中的早期计划/“完成”表述反映当时对话，不等于本次交付状态；请结合根 README 与验证记录判断。
- 导出截止时间见 manifest 的 last_event_at；快照发生在 PR 创建前，因此不包含最终推送/PR 结果。角色过滤和日志完整性已在 manifest 中说明。
